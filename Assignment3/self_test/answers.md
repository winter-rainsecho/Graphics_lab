# Assignment3 自测参考答案（6 核心任务 + 2 Bonus）

> 配套文件：`questions.md`。每题先给出要点，便于自测后核对。

## A. 参数插值（Task 1）
1. **重心坐标 + 透视校正**。屏幕空间用重心坐标 `(α,β,γ)` 插值；但 3D 坐标在投影后不再保持线性比例，必须做透视校正（乘 `1/w`）。
2. **透视校正深度公式**（`rasterizer.cpp:290-292`）：
   - `Z = 1 / (α/w₀ + β/w₁ + γ/w₂)`
   - `zp = (α·z₀/w₀ + β·z₁/w₁ + γ·z₂/w₂) · Z`
   - 一般属性插值同理：`val = (α·v₀/w₀ + β·v₁/w₁ + γ·v₂/w₂) / (α/w₀ + β/w₁ + γ/w₂)`。

## B. 法线可视化（Task 2）
3. `result = (n + 1) / 2`，把法线分量从 `[-1,1]` 映射到 `[0,1]` 作为颜色；**不计算光照**，仅把法线当颜色输出。

## C. Blinn-Phong（Task 3）
4. 用的是 **Blinn-Phong**：高光项用半程向量 `h = normalize(L + V)`，取 `pow(max(0, n·h), p)`。经典 Phong 用 `reflect(-L, n)` 再算 `n·R`。本工程 `reflect()` 函数**未被任何着色器调用**。
5. `1/r²` 是点光源的距离平方衰减（越远越暗）；本作业高光指数 **`p = 150`**。

## D. 纹理映射（Task 4）
6. `kd = 纹理采样色 / 255.f`；`getColor` 用的是 **最近邻**（`std::round` 取最近纹素），既不是双线性也不是双三次。
7. `v` 翻转 `(1-v)` 是因为图像坐标原点在左上、纹理 `v` 习惯从下往上，翻转后对齐。加载时 `cv::cvtColor(RGB2BGR)` 翻转通道顺序（保存前再翻回），复现时需照此链，否则红蓝会反。

## E. Bump Mapping（Task 5）
8. **只扰动法线（TBN 空间），不移动顶点几何**；最后输出扰动后的法线当颜色，**无光照**——本实现实质是"法线贴图可视化"，不是真正打光的 bump。
9. 由法线 `n` 求切线 `t`（当 `s = √(n.x²+n.z²) < 1e-6` 时退化为 `(1,0,0)` 防除零），副切线 `b = n × t`，TBN = `[t | b | n]`。

## F. Displacement（Task 6）
10. 与 bump 前 3 步（构 TBN、采高度图、算梯度得切线空间扰动法线）相同；关键区别在：
    - **(4) 几何位移**：`point += kn * h_uv` 沿原始法线把顶点推出去；
    - **(5) 光照**：把扰动法线喂入 Blinn-Phong 并输出颜色（bump 只输出法线色）。
11. 几何位移量只用 **`kn*h_uv`**（不乘 `kh`）；高度梯度 `dU/dV` 才用 `kh*kn`。

## G. Bonus1 更多模型
12. **程序计算**，非凭空生成几何：每个三角面取两邻边叉积得面法线 → 按顶点累加 → 归一化（简单未加权平均）。原始 `.obj` 几何（顶点/面）来自基线文件，未被改动。
13. 各模型尺度、位置不同；按包围盒求中心与范围，居中并缩放到约 3 单位，才能稳定落入视锥、适配画面（否则会跑出视野或缩成一点）。

## H. Bonus2 双线性纹理插值（Task 7）
14. 取 `x0=floor(u_img), y0=floor(v_img)` 四角 `c00/c10/c01/c11`，先做 x 方向 lerp 得 `top/bot`，再做 y 方向 lerp；坐标映射与 `getColor` **完全一致**：`u_img=u*(W-1)`、`v_img=(1-v)*(H-1)`、对 `u,v` 做 clamp。
15. 放大倍率约 **22×**，双线性只在相邻 4 个纹素间插值、**不能创造细节**，把突变变渐变 → 显“糊”。**最近邻不是抗锯齿**，它恰恰是锯齿/方块来源；双线性只是放大方向的平滑滤波。
16. 命令行：
    - `./Rasterizer out.png bilinear spot`（双线性，用 512×512 小纹理）
    - `./Rasterizer out.png texture spot small`（最近邻，用同一小纹理对比）
    - 纹理越小（如 32×32）差异越明显，但也越糊；128×128 是清晰度与差异的平衡点。
